Hello! This is the GitHub page for the Respawn Menu mod.

Feel free to take a look at the source code!



Below is a description of the mod from Modrinth.

## What it does
This mod simply adds a menu which allows you to respawn quickly and easily. It is activated by pressing the **R** key (no custom keys are available yet).

## How it works
Clicking **R** makes a prompt open. Unless you are on a server, the game should also pause.

If **No** is clicked on the prompt, you return to normal gameplay.

However, if **Yes** is clicked, you die normally. "Normally" means all of your items drop, you are reset to the world spawn, and the death screen shows.

## For servers
On multiplayer servers, the mod **must be installed on both the client and the server** to work correctly.

Otherwise, respawning will not work correctly.
